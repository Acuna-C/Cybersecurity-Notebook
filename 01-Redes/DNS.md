# 🔍 DNS (Domain Name System)

## 1. ¿Qué debo saber?
Sistema distribuido que traduce nombres legibles (ej. `google.com`) a direcciones IP numéricas (ej. `142.250.190.46`).

---

## 2. Tipos de Registros Clave

| Registro | Descripción |
| :---: | :--- |
| **A** | Mapea un dominio a una IPv4. |
| **AAAA** | Mapea un dominio a una IPv6. |
| **CNAME** | Alias de un dominio hacia otro dominio. |
| **MX** | Servidor de correo del dominio. |
| **TXT** | Almacena texto (Usado en validaciones SPF, DKIM, DMARC para anti-phishing). |
| **NS** | Servidor de nombres autoritativo del dominio. |
