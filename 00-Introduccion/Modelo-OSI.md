# 🌐 Modelo OSI

El modelo OSI divide las comunicaciones de red en 7 capas.

## Las 7 capas

|  Nº | Capa          | Función                            |
|----:|---------------|------------------------------------|
|  7  | Application   | Servicios de red para aplicaciones |
|  6  | Presentation  | Formato, cifrado y compresión      |
|  5  | Session       | Gestión de sesiones                |
|  4  | Transport     | Comunicación extremo a extremo     |
|  3  | Network       | Direccionamiento y routing         |
|  2  | Data Link     | Tramas y direcciones MAC           |
|  1  | Physical      | Transmisión de bits                |
